# Imagens da página inicial premium

Pasta destinada às artes individuais da página inicial aprovada da Netinho Auto Parts.

Arquivos sugeridos (WebP com transparência quando adequado):
- `representantes-brasil.webp` — mapa do Brasil 3D com marcador
- `downloads-pdf.webp` — documento PDF com seta de download 3D
- `icone-vendas.webp` — carrinho dourado
- `icone-comissao.webp` — moedas douradas
- `icone-evolucao.webp` — barras douradas de crescimento
- `seta-dourada.webp` — seta de navegação

A arte completa de referência não deve substituir a interface funcional. O cabeçalho, os logotipos das montadoras e o rodapé podem reutilizar os arquivos já existentes.

**Importante:** os nomes acima são uma convenção proposta; as imagens ainda precisam ser adicionadas separadamente.
