# Áudios da LIA — Netinho Auto Parts

Esta pasta guarda as gravações da mascote LIA em formato MP3.

Arquivos previstos:

- `lia-login.mp3` — tela de login
- `lia-inicio.mp3` — página inicial
- `lia-catalogo.mp3` — catálogo
- `lia-clientes.mp3` — clientes
- `lia-pedidos.mp3` — pedidos
- `lia-administracao.mp3` — administração

Envie cada gravação a esta pasta usando exatamente esses nomes. A publicação dos arquivos não conecta automaticamente os botões de áudio; essa integração é feita no código do site.
