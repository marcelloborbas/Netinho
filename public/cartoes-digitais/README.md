# Cartões digitais — Netinho Auto Parts

Armazene aqui os cartões digitais individuais dos vendedores e representantes, em PNG ou WebP.

Padrão de nomes: `jose-burgato.png`, `nome-sobrenome.png` (letras minúsculas, sem acentos e com hífens).

Exemplo de endereço público após publicação: `https://www.netinhoautoparts.live/cartoes-digitais/jose-burgato.png`.

Esta pasta contém as artes para download/compartilhamento. Os botões de baixar e compartilhar no site deverão ser implementados separadamente e vinculados ao usuário autenticado.
