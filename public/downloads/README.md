# Catálogos para download — Netinho Auto Parts

Coloque os catálogos oficiais em PDF nesta pasta com os nomes:

- `fco-catalogo.pdf` — FCO Automotive (ativo)
- `hd-catalogo.pdf` — HD Embreagens (reservado para quando a marca for ativada)

O botão de catálogo no site baixa diretamente `/downloads/fco-catalogo.pdf`, após a publicação. Enquanto o PDF não for adicionado, o botão informa que o arquivo ainda não está disponível.

Não adicione links de terceiros ou documentos não autorizados. Arquivos nesta pasta são públicos.
